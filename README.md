## Overview

Remaining useful life (RUL) models are usually selected by their lowest prediction error, yet a
maintenance decision depends on when an alarm is raised. This repository evaluates four tabular
regressors (linear regression, ridge regression, random forest, gradient boosting) and a 1D
convolutional reference model on all four NASA C-MAPSS subsets through five evaluation lenses:

| Lens | Question | Method |
|---|---|---|
| L1 Accuracy | How accurate and stable is each model? | MAE, RMSE, NASA score over five fold models |
| L2 Separability | Can the models be told apart? | Wilcoxon signed-rank with Holm correction; TOST equivalence within ±2 cycles |
| L3 Error direction | Are errors late or early? | Late, early and severe late counts |
| L4 Life stage | Where along the life do errors fall? | Mean signed error over all 104,897 test cycles |
| L5 Decision | What does acting on the model cost? | Alarm margins calibrated to a common miss target under nested engine-grouped validation; held-out misses and unused life |

The decision lens raises an alarm at the first cycle at which the predicted RUL falls to `L + m`,
where `L` is the maintenance lead time (10, 15 or 30 cycles) and `m` a safety margin. Margins are
calibrated by nested engine-grouped validation, so evaluation engines inform neither the models nor
the margins applied to them. Paired comparisons use a fold-stratified engine bootstrap that
re-estimates every margin in each replicate.

## Installation

```bash
git clone https://github.com/toochii2/isdia2027-rul-decision-evaluation.git
cd isdia2027-rul-decision-evaluation
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

`xz` (standard on Linux and macOS) is used to decompress the predictions. Everything runs on a CPU.

## Reproducing the results

**From the committed predictions** (no training, no raw data needed):

```bash
make unpack      # decompress results/predictions/*.json.xz into results/
make analysis    # recompute every summary result
make figures     # regenerate the figures
make numbers     # print the decision-lens numbers quoted in the paper
```

The bootstrap decision analysis dominates the run time and can take several hours on a laptop;
the other steps take minutes. All random number generators are seeded, and rerunning the analysis
reproduces the committed `results/*.json` files exactly.

**From the raw data** (retrains every model; many CPU hours):

```bash
# place the C-MAPSS files in data/CMAPSSData/ first (see data/README.md)
make models
make analysis figures
```

Tabular models reproduce the committed predictions exactly. CNN predictions can differ slightly
across hardware, PyTorch versions and thread counts.

## Protocol details

- **Data and preprocessing.** All four C-MAPSS subsets (709 training and 707 test engines). Training
  RUL capped at 125 cycles; test labels capped in the same way. For FD002 and FD004, sensors are
  standardised within six operating regimes found by k-means on the operating settings. Sensors with
  a standard deviation below 0.002 are removed, and 5- and 10-cycle causal rolling means and standard
  deviations are added.
- **Models.** Linear regression; ridge (α = 10); random forest (300 trees, depth 14, minimum leaf 4);
  gradient boosting (250 trees, learning rate 0.05, depth 3); 1D-CNN after Li et al. (2018) with 30-cycle
  windows, dropout 0.5, Adam (10⁻³, then 10⁻⁴ for the last quarter of 150 epochs), batch 512.
  Hyperparameters were fixed a priori and not tuned.
- **Resampling.** Engine-grouped 5-fold cross-validation with a deterministic, unshuffled partition.
  Seeds 42 to 46 initialise the five fold models, not the partition. The nested validation adds an
  inner 4-fold loop (seeds 142 + 10k + c) and refits all preprocessing in every split.
- **Decision lens.** Zero-miss and 2% calibration targets; held-out misses with one-sided 95%
  Clopper-Pearson bounds; unused life is the true RUL at the alarm minus `L`, that is, the life left if
  the engine is removed `L` cycles after the alarm.
- **Inference.** Fold-stratified engine bootstrap (B = 2,000) re-estimating every fold's margin;
  p = min{1, 2 min[P(Δ* ≤ 0), P(Δ* ≥ 0)]}. The confirmatory family is the 15-cycle lead with the
  zero-miss target (three contrasts per subset, Holm-adjusted within subset); all other cells are
  exploratory.
